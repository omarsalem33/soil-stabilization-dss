# Logo files

Place the official logos here. The app picks them up automatically (no code change).

| File (any of .png .jpg .jpeg .webp .svg) | Where it appears            |
| ---------------------------------------- | --------------------------- |
| `suez_canal_university.png`              | Left slot of the header     |
| `faculty_of_engineering.png`             | Right slot of the header    |

Tips: use a transparent or white background, roughly square, at least 300x300 px.
Until the files exist, a labelled placeholder box is shown instead.
